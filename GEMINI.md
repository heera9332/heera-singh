## Quick Summary for AI Sessions

1. **Stack:** Next.js 16 (App Router), TypeScript (Strict), Tailwind CSS, shadcn/ui, Lexend Font.
2. **Execution Mode:** 100% Static Export (`output: 'export'`). No runtime server, no API routes, no server actions.
3. **Theming:** Orange theme (`hsl(24.6 95% 53.1%)` / `#f97316`), Dark mode default, Light mode supported.
4. **Positioning:** Freelance Full Stack Web Developer converting visitors to "Start a Project".
5. **Content Separation:** All data models, projects, skills, services, and profile data live in `/data/` and must be strongly typed.
